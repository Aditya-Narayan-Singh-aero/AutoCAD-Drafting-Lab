# 2D Technical Drafting & Geometric Construction

Welcome to my repository for computer-aided drafting and technical graphics! This repository tracks my progression as I build a strong foundation in 2D CAD drafting fundamentals using Autodesk AutoCAD, tailored for mechanical and aerospace engineering applications.

---

## 🚀 Projects Included

* **Mechanical Bracket & Profile Drafting**
  * **Description:** A precise 2D technical drawing of a multi-feature mechanical bracket incorporating complex geometric tangential arcs, angular draft lines, concentric circular bosses, and internal cutout slots.
  * **Concepts Used:** Precision coordinate entry, arc tangent snaps (TTR), angular line construction (114°), offset geometry, concentric circles, line trimming, and BIS/ISO standard dimensioning.
  * **Folder:** `Day01-Mechanical-Bracket/`

* **Parametric Lock Geometry**
  * **Description:** A precise 2D profile of an industrial padlock featuring compound circular arcs, dynamic boundary intersections, a slotted keyhole profile, and curved shackle cutouts.
  * **Concepts Used:** Concentric circle generation (27.5 mm diameter, 68 mm radius), tangent-to-tangent arc sweeps (53 mm radius, 34 mm radius), slot geometry generation (7 mm radius, 22.5 mm offset), line trimming, and radial dimensioning.
  * **Folder:** `Day02-Lock/`

* **Engineering Data & Parameter Table**
  * **Description:** A standardized engineering data table layout featuring structured grid cells, rotated vertical text headers, and linear dimensioning.
  * **Concepts Used:** Precision grid construction, relative coordinate offsets, text placement with 90° rotation angles, vertical annotation alignment, and ISO linear dimensioning (`DIMLINEAR`).
  * **Folder:** `Day03-Table/`

* **Parabola Construction via Tangent Method**
  * **Description:** A precise geometric construction of a parabolic curve using the tangent envelope (oblique rectangle) method within a 160 mm × 240 mm bounding rectangle.
  * **Concepts Used:** Envelope method, proportional line division into equal segments, point-to-point tangent line intersection, smooth spline/curve fitting through tangent envelope points, and standard structural dimensioning.
  * **Folder:** `Day04-parabola-tangent-method/`
 
  *  **Ellipse Construction via Concentric Circles Method**
  * **Description:** A precise geometric construction of a vertical ellipse generated using two concentric guide circles corresponding to the major and minor axes.
  * **Concepts Used:** Concentric circle generation (350 mm major axis, 200 mm minor axis), equal angular division into 12 radial sectors (30° increments), projection line mapping (horizontal intersections from the inner circle, vertical intersections from the outer circle), smooth spline curve fitting through point loci, and standard radial/diameter dimensioning (`DIMDIAMETER`).
  * **Folder:** `Day05-Ellipse-Concentric-Circles-Method/`
